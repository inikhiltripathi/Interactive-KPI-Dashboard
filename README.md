# Interactive-KPI-Dashboard
An interactive Excel dashboard built to analyze e-commerce sales performance using Power Query, Power Pivot, DAX, Pivot Charts, and Slicers.

The dashboard provides business insights into revenue, profit, orders, customer segments, product performance, regional sales, and discount analysis through an interactive interface.

# Project Objective
The objective of this project is to transform raw e-commerce sales data into meaningful business insights by creating an interactive dashboard that helps users:

* Track key business KPIs
* Monitor monthly sales trends
* Analyze category and regional performance
* Identify top-performing products
* Understand customer segments
* Evaluate the impact of discounts on revenue and orders
